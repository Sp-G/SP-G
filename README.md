# MotiveCut — мотивационные нарезки из фильмов

Локальная программа для ПК. Вы загружаете фильм и субтитры и пишете общий смысл ролика.
Программа сама находит подходящие фразы, нарезает их и склеивает в готовое видео.

## Как это работает

1. **Субтитры** (`.srt`, `.vtt`, `.ass`; кодировки UTF‑8 и Windows‑1251) разбираются на реплики.
   Соседние реплики склеиваются в законченные фразы. Если внешних субтитров нет, берутся встроенные из `.mkv`.
2. **Поиск фрагментов** по заданному смыслу, на выбор:
   - **Ключевые слова.** Быстро и полностью офлайн. Учитываются слова из вашего описания и встроенный словарь мотивационной лексики (RU + EN).
   - **Смысловой поиск.** Тоже офлайн, понимает смысл, а не только слова. Нужен `pip install sentence-transformers`.
   - **Claude AI.** Лучшее качество: ИИ читает все субтитры, выбирает сильные фразы и выстраивает из них историю
     (проблема → перелом → кульминация), а для каждого клипа объясняет, почему он выбран. Нужен API‑ключ Anthropic.
3. **Проверка.** Найденные фрагменты показываются в таблице. Можно снять галочки, поправить время начала и конца или поменять порядок.
4. **Сборка.** ffmpeg вырезает каждый клип с небольшим запасом до и после фразы (запас не залезает на соседние реплики).
   Затем приводит клипы к одному формату и склеивает их.

Возможности сборки:
- форматы 16:9 (YouTube), 9:16 с размытым фоном или обрезкой (Shorts / Reels / TikTok), 1:1;
- вшитые субтитры;
- выравнивание громкости между фильмами;
- плавные затемнения между клипами;
- фоновая музыка, которая подмешивается под диалоги.

Можно загрузить **несколько фильмов сразу**. Видео и субтитры сопоставляются по имени файла:
`Rocky.mkv` ↔ `Rocky.srt` / `rocky.ru.srt`.

## Установка и запуск

Нужен **Python 3.10+** ([python.org](https://www.python.org/downloads/), при установке отметьте «Add to PATH»).

- **Windows:** дважды щёлкните `run.bat`.
- **macOS / Linux:** запустите `./run.sh`.

При первом запуске создаётся окружение и ставятся зависимости (несколько минут). После этого в браузере
откроется интерфейс по адресу `http://127.0.0.1:7860`. Всё работает на вашем компьютере, интернет нужен только для режима Claude AI.

**ffmpeg.** Если ffmpeg установлен в системе, используется он. Если нет, программа возьмёт встроенный из пакета `imageio-ffmpeg`.
Для вшивания субтитров нужен ffmpeg с libass. Подходят обычные сборки с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/)
(Windows) и ffmpeg из brew/apt. Путь к своему ffmpeg можно задать переменной окружения `FFMPEG`.

**Большие фильмы.** Если загружать файл через браузер, он копируется во временную папку. Поэтому для фильмов на
несколько гигабайт лучше вставить путь к файлу (или к целой папке) в поле «…или пути к файлам».

**Claude AI.** Получите ключ на [console.anthropic.com](https://console.anthropic.com/). Вставьте его в настройках
в интерфейсе или задайте переменную окружения `ANTHROPIC_API_KEY`. По умолчанию используется модель `claude-opus-5-5`.

Готовые ролики сохраняются в папку `output/`.

## Командная строка

```bash
python -m motivecut.cli --video Rocky.mkv --subs Rocky.srt \
    --theme "никогда не сдавайся, даже когда весь мир против тебя" \
    --duration 60 --format "9:16 размытый фон (Shorts/Reels/TikTok)" --burn-subs \
    --music track.mp3 -o output/rocky.mp4
```

С флагом `--dry-run` программа только покажет найденные фрагменты, без нарезки. С `--method claude` поиск идёт через Claude.

## Структура

| Файл | Что делает |
|---|---|
| `motivecut/subtitles.py` | разбор SRT/VTT/ASS, склейка реплик во фразы |
| `motivecut/selector.py` | поиск фрагментов: ключевые слова / эмбеддинги / Claude |
| `motivecut/video.py` | ffmpeg: нарезка, форматы, субтитры, громкость, склейка, музыка |
| `motivecut/pipeline.py` | связывает всё вместе |
| `motivecut/app.py` | веб-интерфейс (Gradio), запускается локально |
| `motivecut/cli.py` | запуск из командной строки |

Тесты: `pip install pytest && python -m pytest tests`.
